# Security — Patrol & Incident

- **Checkpoint**: titik QR di lokasi (cetak QR dari detail lokasi/checkpoint). **Rute**: urutan checkpoint, estimasi menit, checklist opsional; "Patrol sekarang" untuk ad-hoc.
- **Jadwal**: rute + jam + hari + team/officer default → Patrol Task dibuat otomatis H-1 (atau "Generate dari jadwal").
- **Patrol Tasks**: pantau status, checkpoint ter-scan (x/y, missed). Dialog Checkpoint: tandai manual/missed (alasan) bila perlu — semua tercatat di Activity. Saat officer Selesaikan dengan checkpoint tersisa → otomatis missed (TD-007) + notifikasi supervisor.
- **Incidents**: Report Incident (tipe security, kategori, severity), tugaskan, resolve, tutup; Buat WO bila perlu perbaikan.
- Finding dari patrol → tindak lanjut WO/Incident; notifikasi ke supervisor security.
