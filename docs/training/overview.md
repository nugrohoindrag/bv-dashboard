# Overview — Property/Building Manager

1. **Today (6 counter)**: Open Work Orders, Overdue, SLA Risk, PM Due, Incidents, Tenant Requests. Klik angka → daftar terfilter (filter tersimpan di URL, bisa dibagikan).
2. **Attention Required**: item kritis (overdue, SLA breach, incident kritis, konflik sync) diurutkan severity → umur. Tombol aksi cepat: Tugaskan / Lihat. Filter per domain.
3. **Tenant Requests**: baru hari ini, open, SLA risk + 4 permintaan terbaru.
4. **Today's Operations**: per domain — semua task/WO terjadwal hari ini (timezone property); ringkasan total/overdue.
5. **PM Due 7 hari**, **Team Workload** (open/overdue per assignee), **Building State** (open/overdue/SLA risk/incident per Building/Tower).
6. Latihan: temukan WO overdue → tugaskan ke team Engineering → cek berubah di Team Workload (refresh ≤ 60 dtk).
Property switcher: "Semua properti" hanya untuk Org Admin/Property Manager lintas property.
