# Tenant & Service Request

- **Tenants**: kode otomatis, tipe company/individual, kontak, unit (multi), occupant (kontak utama). Drawer tenant menampilkan SR tenant.
- **Service Request**: Buat SR (tenant → lokasi unit terisi otomatis; kategori → prioritas & team default; channel staff/phone/walk_in/email/whatsapp). Public intake: Settings → Organization → aktifkan per property → bagikan tautan form publik (tenant memantau status dengan nomor SR + telepon).
- SLA: response (acknowledge) dan resolution per prioritas (Settings → SLA Policies); bar SLA di daftar & detail; Menunggu Tenant menghentikan jam SLA.
- Alur: Terima → Tugaskan → Buat Work Order (link dua arah) → WO ditutup ⇒ SR Resolved → Tutup setelah konfirmasi tenant.
