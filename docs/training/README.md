# Materi Training P0 (web dashboard)

Durasi 2 jam per peran. Gunakan org demo (`bvctl seed --demo`) untuk latihan. Semua peran: login, ganti property (header), Global Search (⌘/Ctrl+K), Inbox, logout.

| Peran | Modul | Materi |
|---|---|---|
| Property Manager / Building Manager | [overview.md](overview.md) | Membaca Today, Attention Required, Building State; menugaskan dari Overview; export |
| Operations / Engineering Manager & Supervisor | [operations.md](operations.md), [engineering.md](engineering.md) | Work Order/Task lifecycle, checklist, evidence, SLA, PM plan, aset & QR, Finding → WO |
| Security Manager / Supervisor | [security.md](security.md) | Checkpoint, rute, jadwal patrol, memantau scan, incident |
| Housekeeping Manager / Supervisor | [housekeeping.md](housekeeping.md) | Jadwal cleaning, cleaning ad-hoc, inspeksi, rework |
| Tenant Relations / Ops | [tenant.md](tenant.md) | Tenant & unit, Service Request (telepon/walk-in/public intake), SLA respons |
| Org Admin | [admin.md](admin.md) | Users/roles/teams, checklist template, SLA policy, public intake, sync conflicts, audit log |
