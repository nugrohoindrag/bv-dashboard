# Housekeeping — Cleaning & Inspeksi

- **Jadwal Cleaning**: lokasi + tipe (routine/periodic/deep/spot/special) + jam/hari + checklist + wajib foto → cleaning task otomatis H-1; "Generate" untuk memaksa; "Cleaning ad-hoc" untuk tumpahan/permintaan mendadak.
- **Cleaning**: daftar cleaning task; staff mengerjakan via mobile (foto before/after). Supervisor dapat Tugaskan/Batalkan/Tutup.
- **Inspections**: dari detail cleaning task yang Completed → "Buat Inspeksi Housekeeping" (nomor INS-); isi checklist; Not OK → Finding otomatis → rework Task cleaning (link rework_of).
- Evidence wajib: cleaning task dengan "wajib foto" tidak bisa Selesai tanpa foto after.
